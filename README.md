# Трёхпроходный транслятор с учебного языка на язык Си

---

## Описание проекта

Данный проект представляет собой трёхпроходный транслятор, который переводит программу с псевдо кода на язык **Си**.

Транслятор реализует классическую трёхпроходную схему:

1. **Проход 1 — Лексический анализ**:  
   Исходный текст разбивается на токены `Token`. 

2. **Проход 2 — Синтаксический анализ**:  
   Проверяется правильность грамматики, строится внутреннее представление ast-tree `AST-NODE`.  
   Здесь же выявляются орфографические ошибки `Syntax-Error`.

3. **Проход 3 — Генерация кода**:  
   По ast генерируется корректный код на языке Си, который сохраняется в файл `out.c`.
